Elektron

Edge-deployable peak load forecaster · Mukono District

Elektron forecasts next-hour electrical demand for the Mukono District using a compact neural network distilled from a heterogeneous ensemble.

A teacher ensemble of XGBoost, LightGBM, a BiLSTM and a meta-learner is compressed into a 4,225-parameter MLP. The student is exported to ONNX and served via FastAPI.
