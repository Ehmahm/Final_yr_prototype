Elektron

Peak load forecaster · Edge-deployable · UCU 2026

Elektron forecasts next-hour electrical demand on the Belgian national grid (ELIA, ~10 GW average load) using a compact neural network distilled from a heterogeneous ensemble.

A teacher ensemble of XGBoost, LightGBM, a BiLSTM and a meta-learner is compressed into a 4,225-parameter MLP using structured knowledge distillation. The student is exported to ONNX and served by a FastAPI microservice with a live data fetcher and this dashboard.
