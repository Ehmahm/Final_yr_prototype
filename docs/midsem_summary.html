Problem and Objective

Peak electrical load forecasting underpins smart grid stability, but the most accurate models (large heterogeneous ensembles) are too heavy to deploy on resource-constrained edge nodes that make up modern IoT grids. Lightweight edge models sacrifice accuracy.
Objective: design, implement and empirically evaluate an end-to-end pipeline that compresses a heterogeneous teacher ensemble into a compact, ONNX-deployable student MLP while preserving forecasting accuracy within 3% and achieving >70% model size reduction.

Existing Research and Gap

  • Ensemble learning for load forecasting improves RMSE by 8–12% over single models but is computationally heavy (Wang 2023 Applied Energy; Li 2024 Energy).
  • Knowledge distillation reduces model size by up to 78% with <2% accuracy loss on edge hardware (Hinton 2015; Kumar 2022 IEEE TSG; Deng 2023 Neurocomputing).
  • Feature learning shows 8–17% gains on noisy household data but has not been tested on smooth grid-level signals (Zhang 2023 EPSR; Nguyen 2023 ESWA).

Evidence-based gap (from PRISMA SLR, 15 Scopus studies 2018–2026): No prior work integrates feature learning, ensemble learning and knowledge distillation into a single end-to-end pipeline for peak load forecasting, nor evaluates the compressed model under realistic edge/IoT deployment constraints. Efficiency is reported inconsistently, preventing direct comparison.

Proposed Contribution

  • Integrated pipeline: feature learning → heterogeneous teacher ensemble → distilled student → ONNX edge artifact → FastAPI service → cloud-native deployment.
  • Empirical characterisation of when feature learning helps (household volatility) vs when it does not (smooth grid aggregates) — a domain-specific finding.
  • Quantified compression–accuracy frontier with standardised reporting (MAPE, RMSE, model size, latency, speed-up).
  • Reference implementation deployable on a Raspberry-Pi-class edge node for Ugandan grid operators.

Aggregation-effect finding: same RF model yields 44.86% MAPE on household data and 1.50% MAPE on grid data (30× difference) — confirming peak-load forecasting must be evaluated at aggregate scale. Feature-learning variants were worse than raw windows on smooth grid data (2.56–3.59%) — an honest negative result documented for the report.
